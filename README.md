## Fonctionnalités

- **Upload HQ** : prépare ton edit pour que TikTok ne le compresse pas (60 et 120 FPS), avec diagnostic de l'export et bouton « Publier maintenant ».
- **Téléchargeur** : YouTube, TikTok et Instagram jusqu'en 4K, vidéo ou audio seul (MP3 / WAV), avec option « compatible montage » pour Premiere Pro et After Effects.
- **Interpolation IA** : rends n'importe quel clip ultra fluide (×2, ×4, ×8) ou passe-le en slow motion.
- **22 thèmes + éditeur de thème personnalisé**, en français et en anglais.
- **Mises à jour automatiques** : Lumora te prévient quand une nouvelle version sort et s'installe en un clic.

Rien à installer à côté : tout est inclus dans un seul fichier.

## Installation

1. Télécharge **[Lumora.exe](https://github.com/Kokoalaxx/lumora/releases/latest/download/Lumora.exe)**.
2. Si ton navigateur affiche « fichier peu téléchargé », clique sur **Conserver**.
3. Au premier lancement, si Windows affiche « Windows a protégé votre ordinateur », clique sur **Informations complémentaires**, puis **Exécuter quand même**.
4. Le premier démarrage prend quelques secondes, les suivants sont instantanés.

> Ces avertissements sont normaux pour une application indépendante qui n'est pas encore signée numériquement.

## Configuration requise

- Windows 10 ou 11 (64 bits)
- Environ 500 Mo d'espace disque
- Une carte graphique compatible Vulkan est recommandée pour l'interpolation IA (NVIDIA, AMD ou Intel récente)
